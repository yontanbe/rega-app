# רגע (Rega)

אפליקציית ווב לנשימה, מדיטציה ושינה. בעברית, מימין לשמאל, ואפשר להתקין אותה על הטלפון כמו אפליקציה (PWA).

**כתובת:** https://yontanbe.github.io/rega-app/

## מה יש בגרסה הזו

- **נשימה:** 4 תרגילים (הרגעה, קופסה, 4-7-8, קוהרנטית) עם עיגול מונחה, צליל ורטט.
- **מדיטציה:** טיימר עם פעמון פתיחה וסיום, פעמוני ביניים וצליל רקע.
- **שינה:** גשם, ים, רוח ורעש חום, עם טיימר שינה. ממשיך לנגן כשהמסך כבוי, ויש שליטה ממסך הנעילה.
- **התקדמות:** רצף ימים, דקות, גרף שבועי, היסטוריה ומצב רוח.
- **עזרה עכשיו:** קווי סיוע בישראל ובעולם.
- **עובד בלי אינטרנט** אחרי הביקור הראשון.

כל הצלילים נוצרים בדפדפן (Web Audio), כך שאין קבצי אודיו לאחסן או לרכוש עדיין. כל הנתונים נשמרים רק במכשיר (localStorage).

## התקנה על הטלפון

- **iPhone:** פותחים ב-Safari, לוחצים על כפתור השיתוף, ואז "הוספה למסך הבית".
- **Android:** פותחים ב-Chrome, ובתפריט בוחרים "התקנת אפליקציה".

## פיתוח

```bash
npm install
npm run dev
```

- `npm run lint`: בדיקת טיפוסים.
- `npm run build`: בנייה סטטית לתיקייה `out/`.
- `npm run icons`: יצירת האייקונים מחדש.

כל push ל-`main` נבנה ועולה ל-GitHub Pages דרך `.github/workflows/deploy.yml`.

## השלבים הבאים

לפי תוכנית הבנייה: חשבון משתמש וסנכרון (Supabase), תוכן מוקלט אמיתי על Cloudflare R2, מנויים, ואחר כך רכיב AI עם שכבת בטיחות.

## הבהרה

רגע היא אפליקציה לרווחה אישית. היא לא שירות רפואי ולא מחליפה טיפול.
